# Sistema de Gestão de Vendas

SaaS destinado ao gerenciamento de vendas e operações comerciais para feirantes.

## Objetivo

O sistema tem como objetivo centralizar e organizar:

- Cadastro de clientes;
- Cadastro de produtos;
- Cadastro de fornecedores;
- Controle de estoque;
- Entrada de mercadorias;
- Registro de vendas;
- Contas a receber;
- Controle de devedores;
- Cobranças;
- Pagamentos;
- Devoluções e estornos;
- Geração de romaneios;
- Histórico e auditoria das operações.

## Arquitetura

O projeto será desenvolvido utilizando uma arquitetura baseada em:

- Frontend web;
- API/Backend;
- PostgreSQL;
- Supabase como serviço de banco de dados;
- Sistema multi-tenant.
